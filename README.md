## OneQuick 现在有什么优惠，能省多少

## 几个容易忽略的坑

买断不等于永久全功能，只保 OneQuick 10。这是最容易被“lifetime license”这个说法误导的地方，官方的英文表述是 includes all features within the major version，括号里那句才是关键。

订阅默认自动续费。到期不取消就会继续扣款。从订阅转买断的人，官方特别提醒先取消自动续费再买断，否则会被扣两次钱。

兑换时登录的微软账号别搞错。授权和兑换码都绑账号，登错账号处理起来很麻烦，官方 FAQ 把这条单独列了出来。

付款走的是微软商店，官网没有单独写退款条款，售后按微软商店的流程处理。下单前在结算页确认一下。

公开的独立测评不多。这款工具在中文互联网上的讨论量有限，能查到的信息主要来自官网文档和微软商店页面，所以上面这些判断基本是从功能表和定价结构推出来的，不是从一堆测评里汇总的。

## 常见问题

**OneQuick 有免费版吗，够不够用？**
有，功能不算阉割版，屏幕边缘、复制搜索、短语替换、输入监控都能用，也允许商用。限制在主屏、条数上限和配置同步这几项，轻度使用碰不到。

**订阅版和买断版哪个划算？**
用不满四年选订阅，$4.99 一年；确定长期用选买断，$19.99 大约等于四年订阅费。买断只保 OneQuick 10 这个大版本，这点要算进去。

**一个授权能装几台电脑？**
一个微软账号最多绑定 10 台设备，在微软账号的设备管理页面可以自己调整。

**买了之后大版本更新还要再付钱吗？**
订阅版在订阅期内可以用当时的全部专业功能；买断版只覆盖 OneQuick 10，下一代主版本需要重新购买。

**有学生优惠或者优惠码吗？**
官网没有公开的优惠码机制，付款走微软商店，没有填码的地方。荔枝商店那边能用的是平台首单券和会员日积分，属于全站活动。
